# Troubleshooting — Stock Melania

Se completa a medida que aparezcan casos reales.

- App no levanta local: verificar `.env.local` completo y `npm install`.
- Deploy falla en Vercel: ver logs del build en el dashboard de Vercel.
- Volver a versión anterior: Vercel → Deployments → Promote, o `git revert` + push.
